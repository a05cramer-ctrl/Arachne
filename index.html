    What is built, and what comes after, in order. No dates: a phase is marked shipped only when it runs.
    
    
    
      
    01NEXT
    the web
    • spiders online, real headless browsers, polite by construction
    • novelty gate: only what is new is kept
    • a receipt written for every kept page
    
      
    02THEN
    the anchor
    • a Solana program stores one merkle root per sealed epoch
    • public API: /v1/web, /v1/pages, /v1/proof
    • proofs checked against the on-chain root
    
      
    03THEN
    nephila
    • tokenizer trained on the crawl
    • first pretraining run, from random weights
    • weights public, dataset root inside the checkpoint
    
      
    04LATER
    the open nest
    • anyone can run a spider on their own machine
    • false receipts are rejected by the other spiders
    • a bigger nephila every time the dataset doubles
